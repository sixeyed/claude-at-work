what's coming up in the next version of .net?

Claude 2026-04-27  09:00

The next version is .NET 11, currently in Preview 3. Here's what's coming:

Release Timeline

It's a Standard Term Support (STS) version scheduled for final release in November 2026, with two years of support.

Runtime & Performance
  • Runtime-native async — cleaner stack traces and lower overhead. As of Preview 3, no longer requires opting in via a project flag for net11.0 targets.
  • JIT improvements — bounds check elimination, redundant checked context removal, switch expression folding, and new Arm SVE2 intrinsics.
  • Updated minimum hardware requirements for x86/x64 and Arm64, requiring more modern instruction sets.
WebAssembly & Mobile
  • CoreCLR becomes a target in the .NET WebAssembly SDK (used by some Blazor variants) and the default runtime for Android builds, furthering the goal of eliminating Mono dependencies.
  • WebAssembly improvements: WebCIL payload loading and better debugging symbols.
Libraries
  • Native Zstandard compression support with improved performance.
C# 15
  • Collection expression arguments — lets you customise a collection at creation time, e.g. setting capacity or a custom comparer inline: List<string> names = [with(capacity: values.Count * 2), .. values];
Community Reaction

Mixed so far. Early developer feedback has focused on concerns about C# syntax complexity and the framework's strategic emphasis on agentic AI over core framework polish.

Preview 3 is available to download now at dotnet.microsoft.com.
